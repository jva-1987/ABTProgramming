Error codes

The output pin [ErrCode] indicates the error code that occurred during the last read access of the function block to the BACnet object.

[ErrCode] can be used to test the control program in the Programming editor online mode. In normal mode, the program can use it to troubleshoot specific exceptions, such as values that are above or below the specified range.

  • [ErrCode] = 0 indicates no fault.
  • [ErrCode] > 0 indicates a fault.

ErrCode < 20 and ≥ 256

Error codes with values < 20 and ≥ 256 are derived from the evaluation of the reliability property of the BACnet object. These error codes may indicate problems with field devices.

ErrCode ≥ 20 and < 256

Error codes with values between 20 and 256 indicate a problem with the relationship between a function and a BACnet object (data point). For example, there may be difficulties accessing the object and/or its required properties. Function blocks and/or data point configuration values may be set incorrectly.

Troubleshooting

If the error code indicates a problem with the device ID or object ID of the function block, ensure that the referenced BACnet object is compatible with the function block.

Function block access to the gather view nodes object:

  • The object ID displays a gather view node object (must be the same device).
  • The referenced BACnet object must be compatible with the function block type.
