Configurator

Program blocks are stored in the library without I/Os. Use the auto-create and auto-connect functions to create I/Os and/or to connect them to the interface blocks, e.g., R_A, CMD_B. Alternatively, take the I/Os from the folder containing the predefined I/Os in the library and/or from the plant and connect them to the interface blocks.

Function

Determines the appropriate control action (heating or cooling) for the energy recovery units by comparing the extract air enthalpy to the outside air enthalpy. If the extract air enthalpy is greater than the outside air enthalpy, the system initiates heating; otherwise, it initiates cooling. If the humidity sensor is unreliable, the function reverts to comparing temperatures.
