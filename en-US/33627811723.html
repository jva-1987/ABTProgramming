[IcPrt21] Anti-icing protection function

Program block, name / node subtype: [IcPrt21] Anti-icing protection function

Library hierarchy: Ventilation and air conditioning equipment

Family: IcPrt

Configurator

Program blocks are stored in the library without I/Os. Use the auto-create and auto-connect functions to create I/Os and/or to connect them to the interface blocks, e.g., R_A, CMD_B. Alternatively, take the I/Os from the folder containing the predefined I/Os in the library and/or from the plant and connect them to the interface blocks.

Function

Provides anti-icing protection for an energy recovery unit.

The binary calculated value IcPrt indicates that anti-icing protection is active. When anti-icing protection is monitored via a differential pressure sensor, this object triggers an alarm if the protection remains active for an extended period (e.g., more than 15 minutes).

Optional functions

This program block has the following optional functions:

Option: Differential pressure monitor (1xBI)

Reads the signal from a differential pressure monitor over the energy recovery. If the differential pressure increases due to ice formation on the surface of the energy recovery aggregate, the system reduces the output of the temperature controller.

Option: Differential pressure sensor (1xAI)

Reads the signal from the differential pressure sensor and sends the value to the anti-icing protection logic.

It also compares the measured pressure to a predefined upper limit. If the pressure exceeds this threshold, an alarm is triggered.

Further options that belong to this option:

- Option: Setpoint differential pressure

Static setpoint for anti-icing protection (analog configuration value).

- Option: Differential pressure setpoint based on extract air fan speed

Dynamic setpoint for anti-icing protection. The setpoint is calculated using CHAR_LIN in the program based on the fan speed.

- Option: Differential pressure controller

PID controller that compares the differential pressure to a static or dynamic setpoint and limits the output of the temperature controller for anti-icing protection.

- Option: Differential pressure control, 2-point

The logic reduces the output of the temperature controller for anti-icing protection if the differential pressure rises above a static or dynamic setpoint.

Option: Exhaust temperature after energy

Performs anti-icing protection using a PID controller that limits the output of the temperature controller.

Option: Glycol temperature (1xAI)

Performs anti-icing protection using a PID controller that limits the output of the temperature controller.

In the event of a disturbance from this program block, the program logic in the energy recovery and air handling unit ensures that the plant stops. All outputs are commanded with a higher priority.
