[HydChovr21] Hydraulic for changeover, 4 shutoff valves

Program block, name / node subtype: [HydChovr21] Hydraulic for changeover, 4 shutoff valves

Library hierarchy: Universal equipment

Family: HydChovr

Project tree

Diagram

Configurator

Program blocks are stored in the library without I/Os. Use the auto-create and auto-connect functions to create I/Os and/or to connect them to the interface blocks, e.g., R_A, CMD_B. Alternatively, take the I/Os from the folder containing the predefined I/Os in the library and/or from the plant and connect them to the interface blocks.

Function

Operates the four optional shutoff valves to ensure proper circulation based on the heating or cooling mode.

Optional functions

This program block has the following optional functions:

Option: Shutoff valve flow for cooling (1xBO, 2xBI)

Controls a flow shutoff valve (Vlv21) that opens when the cooling state is active.

Option: Shutoff valve flow for heating (1xBO, 2xBI)

Controls a flow shutoff valve (Vlv21) that opens when the heating state is active.

Option: Shutoff valve return for cooling (1xBO, 2xBI)

Controls a return shutoff valve (Vlv21) that opens when the cooling state is active.

Option: Shutoff valve return for heating (1xBO, 2xBI)

Controls a return shutoff valve (Vlv21) that opens when the heating state is active.
