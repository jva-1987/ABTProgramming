[PrdvHCtl21] Predictive heating control

Program block, name / node subtype: [PrdvHCtl21] Predictive heating control

Library hierarchy: Heating functions

Family: PrdvHCtl

Project tree

Diagram

Configurator

Program blocks are stored in the library without I/Os. Use the auto-create and auto-connect functions to create I/Os and/or to connect them to the interface blocks, e.g., R_A, CMD_B. Alternatively, take the I/Os from the folder containing the predefined I/Os in the library and/or from the plant and connect them to the interface blocks.

Function

This function is used in hot water systems to optimize room temperature control for heating plants. It uses a model predictive heating control algorithm.

Optional functions

This program block has the following optional functions:

Option: Room temperature

Reads the room temperature and provides it to the model predictive heating control algorithm.

Option: Outside air temperature forecast

Collects external predictions for 24 outside air temperatures.
