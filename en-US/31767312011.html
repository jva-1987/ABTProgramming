[Vlv28] Valve, heating/cooling function & 2 BI for feedback

Program block, name / node subtype: [Vlv28] Valve, heating/cooling function & 2 BI for feedback

Library hierarchy: Universal equipment

Family: VlvShof

Project tree

Diagram

Configurator

Program blocks are stored in the library without I/Os. Use the auto-create and auto-connect functions to create I/Os and/or to connect them to the interface blocks, e.g., R_A, CMD_B. Alternatively, take the I/Os from the folder containing the predefined I/Os in the library and/or from the plant and connect them to the interface blocks.

Function

Controls a changeover valve (2-position) function and reads optional feedback signals.

The opening and closing time can be parameterized in the program.

Optional functions

This program block has the following optional functions:

Option: Feedback for heating state (1xBI)

Reads the end switch of the actuator for the heating position of the valve.

Option: Feedback for cooling state (1xBI)

Reads the end switch of the actuator for the cooling position of the valve.

The program logic reads the binary command, considers the opening and the closing time, compares the signals from the end switches of the actuator from the option "Feedback for heating state" and/or "Feedback for cooling state" to the command and can generate two alarms (binary calculated values): "Position monitoring (Heating state)" and "Position monitoring (Cooling state)".

Option: Kick function

Prevents standstill damage by generating a pulse that opens the valve at a configured time with a defined pulse length after a minimum off time has elapsed.

This is configured in the program.
