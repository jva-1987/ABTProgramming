[ReCCtl21] Sensors, setpoints and control for recooling unit

Program block, name / node subtype: [ReCCtl21] Sensors, setpoints and control for recooling unit

Library hierarchy: Cooling and refrigeration equipment

Family: ReCCtl

Project tree

Diagram

Configurator

Program blocks are stored in the library without I/Os. Use the auto-create and auto-connect functions to create I/Os and/or to connect them to the interface blocks, e.g., R_A, CMD_B. Alternatively, take the I/Os from the folder containing the predefined I/Os in the library and/or from the plant and connect them to the interface blocks.

Function

Performs temperature control for the cooling water flow temperature.

The cooling water temperature control setpoint is lowered by a small offset defined by an analog configuration value, and the slightly lower cooling water temperature setpoint is sent to the unit.

Optional functions

This program block has the following optional functions:

Option: Setpoint cooling water temperature

A configuration value for setpoint cooling water temperature

Option: Setpoint offset

A configuration value that shifts the cooling water temperature setpoint.

Option: Outside air temperature (1xAI)

Creates an analog input for outside air temperature and reads its signal.
