[HCcrPltMod23] Plant operating mode determination heating/cooling circuit, for room temperature control

Program block, name / node subtype: [HCcrPltMod23] Plant operating mode determination heating/cooling circuit, for room temperature control

Library hierarchy: Universal equipment

Family: HCcrPltMod

Project tree

Diagram

Configurator

Program blocks are stored in the library without I/Os. Use the auto-create and auto-connect functions to create I/Os and/or to connect them to the interface blocks, e.g., R_A, CMD_B. Alternatively, take the I/Os from the folder containing the predefined I/Os in the library and/or from the plant and connect them to the interface blocks.

Function

Determines the plant operating mode from multiple sources (e.g., scheduler, manual operation, room unit), establishes the heating or cooling state, provides a room temperature setpoint to a hydraulic circuit, and switches it on or off.

The program block is for plants with room temperature control.

Possible operating modes

Operating mode

Description

Protection

The hydraulic circuit is off (the pump is off and the valve is closed).

The room cooling setpoint for Protection or the room heating setpoint for Protection is active.

Economy

The hydraulic circuit is on (the pump is on and the valve follows the output of the temperature controller).

The room cooling setpoint for Economy or the room heating setpoint for Economy is active.

Pre-Comfort

The hydraulic circuit is on (the pump is on and the valve follows the output of the temperature controller).

The room cooling setpoint for Pre-Comfort (calculated from the room cooling setpoint for Comfort plus the delta cooling setpoint for Pre-Comfort) or the room heating setpoint for Pre-Comfort (calculated from the room heating setpoint for Comfort minus the delta heating setpoint for Pre-Comfort) is active.

Comfort

The hydraulic circuit is on (the pump is on and the valve follows the output of the temperature controller).

The room cooling setpoint for Comfort or the room heating setpoint for Comfort is active.

Off

The hydraulic circuit is off (the pump is off and the valve is closed).

The room cooling setpoint for Protection or the room heating setpoint for Protection is inactive.

This operating mode is only active for a very short time during start-up after power-on or when the parameter for the function that prevents the plant from running is switched on.

The operating mode is shown on BACnet with a multistate calculated value "Present operating mode" with the states "Protection", "Economy", "Pre-Comfort", "Comfort", and "Off".

A parameter in the program is preset to prevent the plant from running. This is useful for testing data points. It must be switched off to start the plant.

"Startup function and alarm handling" controls the startup behavior of the plant after power-on. There is a delay after startup, "DlySttUp", of about 50 seconds. Do not change this delay. Change the delay "DlyOn" so that it is different for each plant. This ensures that plants start one after another and do not overload the electrical system. There is also a collection and aggregation of all faults and alarms from the plant. If a local alarm lamp and/or reset button is required, an alternative can be selected.

The room temperature is used for several functions:

The plant switches on when the room temperature rises above a "Cooling setpoint for protection", e.g., 40 °C and switches off with a hysteresis of, e.g., 5 K.

The plant switches on when the room temperature falls below a "Heating setpoint for protection", e.g., 12 °C and switches off with a hysteresis of, e.g., 2 K.

A logic determines a heating or cooling state based on different conditions and sources (HCChovr21).

If there is no preselection for heating or cooling, the system compares the room temperature with the heating and cooling setpoints to determine the appropriate state.

Optional functions

This program block has the following optional functions:

Option: Condensation monitor (1xBI)

Reads the signal from a condensation monitor and stops the plant.

Option: Dew point temperature calculation (1xAI)

Creates an analog input for room air humidity and reads its signal. It calculates the dew point temperature and adds an offset, e.g., 1 K. The resulting dew point temperature is displayed as an analog calculated value.

Option: External off

Interface that can be connected to a program logic for shutting down the plant. It goes into Protection mode.

Option: Optimum start stop control for cooling

Performs optimum start stop control (using the program block OsscFnct21) when the plant is in automatic mode (no manual intervention or external on or off).

Option: Optimum start stop control for heating

Performs optimum start stop control (using the program block OsscFnct21) when the plant is in automatic mode (no manual intervention or external on or off) and released by the optional heating limit functionality.

Option: Request from room operator unit

A binary simple process value that can be read/written from the device chart of a room unit. It can switch on the plant.

Option: Timer button (1xBI)

Reads the state of a timer button and switches the plant on for a specified time (adjustable in the program).

Option: Switch off in Economy mode when room temperature higher than setpoint

If the current operating mode is Economy and the room temperature exceeds the "Heating setpoint for economy", the hydraulic circuit is switched off with a hysteresis of, e.g., 2 K.

Option: Switch off in Economy mode when room temperature lower than setpoint

If the current operating mode is Economy and the room temperature falls below the "Cooling setpoint for economy", the hydraulic circuit is switched off with a hysteresis of, e.g., 2 K.

Option: Operating mode switch (1xMI=2xBI)

Reads the state of an operating mode switch, normally at the front of the electrical panel, and has the states "Auto", "Protection", and "Comfort".

Option: Operation indication (1xBO)

Commands a lamp (usually green) that turns on if the plant is running or that blinks if a switching operation is in progress.

Option: Scheduler

Scheduler of type MSCHED with the states "Protection", "Economy", "Pre-Comfort", and "Comfort" that switches the plant off and on.
