[CMP_SN] Compare serial number

CMP_SN compares the serial number of a controller to a value configured at an input and provides the result at an output.

Functioning

CMP_SN reads the serial number of a controller from the device object and compares it, case-sensitively, to the value configured at the [SnDev] input. The result of the comparison is provided at the [EqSn] output.
