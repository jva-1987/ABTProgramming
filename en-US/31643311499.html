[HydCrtC23] Hydraulic circuit for cooling, room temperature control

Program block, name / node subtype: [HydCrtC23] Hydraulic circuit for cooling, room temperature control

Library hierarchy: Cooling and refrigeration equipment

Family: HydCrtC

Project tree

Diagram

Configurator

Program blocks are stored in the library without I/Os. Use the auto-create and auto-connect functions to create I/Os and/or to connect them to the interface blocks, e.g., R_A, CMD_B. Alternatively, take the I/Os from the folder containing the predefined I/Os in the library and/or from the plant and connect them to the interface blocks.

Function

Controls the room temperature.

The program receives a setpoint for the room temperature for cooling and displays it on BACnet with a calculated value object. It contains a PID controller that changes the valve position to control the room temperature. The pump runs when the function is on.

A parameter in the program defines whether the plant stops if the room temperature sensor has a fault.

Optional functions

This program block has the following optional functions:

Option: Chilled water demand

Generates a chilled water demand and displays it on BACnet with a calculated value object.

Option: Pump activation at low outside temperature

The pump always runs below a certain limit for the outside temperature. This is to increase the frost protection.

Option: Flow temperature (1xAI)

Creates an analog input for the flow temperature and reads its signal. It can generate an alarm (high and low limit).

Option: Return temperature (1xAI)

Creates an analog input for the return temperature and reads its signal. It can generate an alarm (high and low limit).

Option: Minimum flow temperature limitation based on dewpoint temperature

A PID controller keeps the flow temperature above the dewpoint temperature.

This option can only be applied successfully together with the optional flow temperature.

Option: Switch-off delay for pump

Defines a switch-off delay for the pump. It is preset to be short and is parameterizable in the program.
